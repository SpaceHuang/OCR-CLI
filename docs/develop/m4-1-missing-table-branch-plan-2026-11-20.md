# M4.1 缺失表格分支开发计划（2026-11-20，v1.1 评审修订）

**状态：** v1.1（回应评审 `docs/review/m4-1-missing-table-branch-plan-2026-11-20-review.md` 的 4 项阻断——人群冻结、触发收窄、持久化设计、回归门重构；评审口径修正一并处理）
**人群冻结产物：** `benchmarks/omnidocbench/reports/analysis/analysis-f6-population-freeze.json`（逐页 detection_N/block_N/发射形态/处置类别，review BLK-3 解除条件）
**数据依据：** `benchmarks/omnidocbench/reports/analysis/analysis-lesion-attribution-ovisocr3.json`（OvisOCR3 默认基线的 <0.5 病灶归因）——53 张 0 分表格中 **32 张模型未输出任何 `<table>` 块**（内容退化为纯文本）、21 张结构错配；**53/53 页面均被 sidecar 表格区域检出**（97.3% 召回的 PP-DocLayoutV2 完全覆盖）；73 张 <0.5 慢性表中双模型取优 oracle 仅 0.154（换模型无空间；v1.0 误写 54，依归因 JSON 修正）。
**关联计划：** `m4-table-reopen-development-plan-2026-11-16.md`（v1.6，管线基础设施全部复用）；`ovisocr3-default-switch-plan-2026-11-18.md`（当前基线 = OvisOCR3，Overall 90.87）。
**方案性质：** M4 管线的**增量分支**（F6 触发），不推翻已判 NO-GO 的 M4 主体（已输出表格的重读人群）——两个人群互斥，证据独立。

## 1. 机制缺陷（为什么这是新方向而不是旧 M4 复活）

M4 触发器 F1–F5 全部作用于**已输出的表格 HTML 块**。0 分表的失败模式是**页面根本没有表格块**（模型把表格内容当普通文本输出）——触发器在这类页面**结构性永不触发**，重读管线永远够不到。这不是"重读无增益"（B2 战役的 Δ≈0 结论测的是已输出表格的人群），而是**管线覆盖不到**。

区域信号完全现成：sidecar（PP-DocLayoutV2，route A）在 53/53 的 0 分页面上检出表格区域。缺失的只是触发分支与替换规则。

## 2. 目标人群与杠杆（v1.1 冻结，review BLK-3 解除）

人群按 **block 级**定义（page_json 的 HtmlTable 块数），非原始 `<table` 标记计数——未闭合标记的页在块级同样是零表格块，F6 同样适用。冻结口径与逐页清单见 `analysis-f6-population-freeze.json`：

| 子群 | 页数 | GT 表 | 发射形态 | v1 处置 |
|---|---|---|---|---|
| raw_replace | 13 | 15 | 模型输出了**未闭合的 `<table` 片段**（截断/畸形，解析不成块），标记后无正文（实测 13/13） | **标记→文末整体替换**为重读表 |
| empty_append | 5 | 13 | 页面输出为**空**（退化到零输出） | 追加重读表 |
| excluded | 4 | 5 | raw_table 后有 1–2 行正文（2 页）/ 表格内容嵌入散文无连续锚点（2 页） | **v1 不触发**（无安全处置），入档 |
| 部分缺表（blocks>0, det>blocks） | 17 | 72 | 部分输出 | **v1 不触发**（整页跳过，D-44 保留——review BLK-1） |
| det==blocks（旧 M4 人群） | 401 | — | 已输出表格 | 不在本计划（NO-GO 证据不变） |

**杠杆（修正，review BLK-3）**：v1 触发人群 = **18 页 / 28 GT 表**；全部修到全集表格均值 0.86 = 28×0.86/665/3×100 ≈ **+1.21 Overall**（v1.0 的 +2.9 系人群口径错误，53 张零分表 ≠ F6 触发表；28 张中 32→28 的差值即 excluded 与部分缺表的折损，已如实入账）。`other` 语言 text 回退等口径以冻结产物为准。

**机制要点（v1.1 确认）**：F1–F5 检查**已输出表格块**——零表格块页面上结构性永不触发，spike 归因干净（F6 与 F1–F5 人群互斥由"块数 = 0"保证，非假设）。

## 3. 决策

| ID | 决策 | 理由 |
|---|---|---|
| D-53（v1.1 修订，review BLK-1） | **F6 v1 触发域 = block_N == 0 且 det_N > 0 的页面**（零表格块页）；部分缺表页（blocks>0, det>blocks）**维持 D-44 整页跳过**——前缀序数配对无法识别首/中/尾部缺失，身份歧义未解前不纳入。检出区域数与 GT 无关，运行时只看区域与块 | 7 页零标记 + 15 页未闭合标记在块级全部为零表格块（22 页）；部分缺表的 17 页 72 表留待对齐契约专项（评审解除条件选项 a） |
| D-54（v1.1 修订，review BLK-2/4） | **持久化与处置规则按发射形态冻结**：① raw_replace（13 页）= 标记→文末**整体替换**（实测 13/13 标记后无非表格正文，2 页有正文尾巴的已剔除出触发域）；② empty_append（5 页）= 文末追加；③ **原纯文本零删除**（v1 无安全定位规则，重复内容如实入账；text 分量回归门 T4 实测）；④ 结构有效性门（可解析 + ≥2×2 + 非全空）**仅是必要条件**，追加内容归属门 = 重读输出与原 md 表格尝试文本的 bigram 覆盖（raw_replace 页有锚可查；empty 页无锚，结构门 + T4 人工抽验背书，风险如实标注） | 评审 BLK-2 要求冻结插入/锚点/处置；发射形态实测使 13 页替换锚点唯一（标记字符位）；"非空 2×2 = 误检防护"表述撤回（0.8284 是精确率非误检防护），代之以内容归属门 |
| D-55（v1.1 澄清，review 口径修正 2） | `reread_rules_generation` 字段沿用，**值由 1 升至 2**（F6 是新增触发输入 = 行为变更）；resume 回归：generation 2 的 F6 产物不被 generation 1 的旧运行复用，反之亦然 | v1.0 的"不变/＋1"矛盾消除 |
| D-56（v1.1 修订，review BLK-1） | **v1 无配对**：零表格块页面上所有检出区域视作缺失，按 bbox 阅读序逐个裁剪重读（无序数歧义——没有可错配的输出块）；部分缺表页整页跳过 | D-44 序数保护完整保留（review 解除条件 a） |
| D-57 | 范围 = 表格；公式不纳入 F6（B0' 公式检测门 ~60% 未过，无合格区域信号；M5 维持关闭，重开条款不变） | 公式区域来源仍未解决；表格区域 53/53 覆盖 |

## 4. 任务分解

| 任务 | 内容 | 验收 |
|---|---|---|
| T1 | F6 触发实现（块级）：编排入口比较 det_N 与输出表格**块数**；块数 = 0 → 全区域按 bbox 阅读序裁剪重读；blocks>0 → 既有路径（部分缺表整页跳过） | 单测：零块页全区域重读（1/2/4 区域）；有块页走 F1–F5 不进 F6；det_N=0 零触发 |
| T2 | 持久化（D-54）：raw_replace 页 = 定位 `<table` 标记字符位、标记→文末替换为重读表（页面无正文尾巴由触发域保证，替换前**逐页断言**、断言失败保原并计 f6_rejected）；empty_append 页 = 文末追加；page_json 块按 bbox 序插入；零删除 | 端到端验收：0→1、0→2 新表；非目标正文（标记前文本/其他块）逐字节不变；md/page_json 一致；checkpoint 哈希对应新产物；导出器表格键序正确 |
| T3 | 内容归属门 + 计数器：raw_replace 页重读输出与原表格尝试文本 bigram 覆盖 ≥ 冻结阈值才采用；`f6_triggered/f6_emitted/f6_rejected`（逐表，含区域 ordinal 与分支标记 F6）入 RereadStats detail 与 result | 归因单测 + golden |
| T4 | **18 页冻结人群 spike**（`analysis-f6-population-freeze.json` 清单）：两臂分测——raw_replace 13 页（15 表）/ empty_append 5 页（13 表）；`--table-reread on` + 现配置（OvisOCR3）；官方逐表 TEDS + **text 分量前后对比**；人工抽验 10 张 | **spike 判据（预注册）**：① raw_replace 臂 TEDS ≥ 0.5 比例 ≥ 60%；② text 分量不低于基线；③ 非目标 440 页 f6_triggered = 0 且产物逐字节不变；任一未达 → 停止归因 |
| T5 | T4 过线 → B2 适配战役（28 表人群 + 全集回归门）→ 转正判定 | 与 M4 同构门禁 |

## 5. 风险与边界

| 风险 | 缓解 |
|---|---|
| 直采引入幻觉/低质表（无 compare-keep 基线，review BLK-4） | 双门：结构有效性（必要条件）+ 内容归属门（raw_replace 页有原尝试文本可查）；empty 页无锚 = 最弱环节，如实标注，靠 T4 人工抽验 + text/TEDS 双回归门兜底；97.3% 是召回率非误检防护（v1.0 表述撤回） |
