# M4.1 缺失表格分支开发计划（2026-11-20，v1.1 评审修订）

**状态：** v1.2（重审 `docs/review/m4-1-missing-table-branch-plan-2026-11-20-re-review.md` 的 3 项 RBLK 处置——458 页对账总账、发射形态前置资格判断、两臂全分母判据）
**人群冻结产物：** `benchmarks/omnidocbench/reports/analysis/analysis-f6-population-freeze.json`（v2：**458 页完整对账总账**，逐页 detection_N/block_N/disposition/GT 表键；RBLK-1 解除条件）
**数据依据：** `benchmarks/omnidocbench/reports/analysis/analysis-lesion-attribution-ovisocr3.json`（OvisOCR3 默认基线的 <0.5 病灶归因）——53 张 0 分表格中 **32 张模型未输出任何 `<table>` 块**（内容退化为纯文本）、21 张结构错配；**53/53 页面均被 sidecar 表格区域检出**（97.3% 召回的 PP-DocLayoutV2 完全覆盖）；73 张 <0.5 慢性表中双模型取优 oracle 仅 0.154（换模型无空间；v1.0 误写 54，依归因 JSON 修正）。
**关联计划：** `m4-table-reopen-development-plan-2026-11-16.md`（v1.6，管线基础设施全部复用）；`ovisocr3-default-switch-plan-2026-11-18.md`（当前基线 = OvisOCR3，Overall 90.87）。
**方案性质：** M4 管线的**增量分支**（F6 触发），不推翻已判 NO-GO 的 M4 主体（已输出表格的重读人群）——两个人群互斥，证据独立。

## 1. 机制缺陷（为什么这是新方向而不是旧 M4 复活）

M4 触发器 F1–F5 全部作用于**已输出的表格 HTML 块**。0 分表的失败模式是**页面根本没有表格块**（模型把表格内容当普通文本输出）——触发器在这类页面**结构性永不触发**，重读管线永远够不到。这不是"重读无增益"（B2 战役的 Δ≈0 结论测的是已输出表格的人群），而是**管线覆盖不到**。

区域信号完全现成：sidecar（PP-DocLayoutV2，route A）在 53/53 的 0 分页面上检出表格区域。缺失的只是触发分支与替换规则。

## 2. 目标人群与杠杆（v1.1 冻结，review BLK-3 解除）

人群按 **block 级**定义（page_json 的 HtmlTable 块数），非原始 `<table` 标记计数——未闭合标记的页在块级同样是零表格块，F6 同样适用。冻结口径与逐页清单见 `analysis-f6-population-freeze.json`：

| 子群 | 页数 | GT 表 | 发射形态 | v1 处置 |
|---|---|---|---|---|
| f6_raw_single | 11 | 11 | 未闭合 `<table` 片段、标记后无正文、**det_N = 1**（原文整段归属单区域，无切分歧义） | **标记→文末整体替换**为重读表 |
| f6_empty | 5 | 13 | 页面输出为**空**（退化到零输出） | 追加重读表 |
| f6_raw_multi_excluded | 2 | 4 | 未闭合片段但 det_N ≥ 2（多区域共享整段原尝试文本，逐区域切分不安全） | **v1 不触发**（review BLK-1 解除条件：无法安全切分的多表页排除） |
| excluded_text_only | 4 | 5 | 表格内容嵌入散文无连续锚点（2 页）/ raw_table 后有正文尾巴（2 页） | **v1 不触发** |

**杠杆（v1.2 冻结）**：触发人群 = **16 页 / 24 GT 表**；全部修到全集表格均值 0.86 = 24×0.86/665/3×100 ≈ **+1.03 Overall**（逐级收窄：53 零分表 → 32 零块键 → 24 触发表，每步折损在冻结产物中可复核）。

**机制要点（v1.1 确认 + v1.2 补强）**：F1–F5 检查**已输出表格块**——零表格块页面上结构性永不触发，spike 归因干净。**458 页对账总账**已建（RBLK-1 解除）：32 零块键与归因基线一致（33−1 = anomaly 页 TEDS 1.0，非病灶）；页面分类 458 = 2+11+5+4+17+401+17+1 无遗漏无重叠，非目标页 = 442（458−16）。

## 3. 决策

| ID | 决策 | 理由 |
|---|---|---|
| D-53（v1.2 修订，re-review RBLK-2） | **触发资格 = 发射形态前置判断 + 块级条件，全部在解码前完成**：block_N == 0 且 det_N > 0 时，运行时检查页面 md 的发射形态——① 空（empty_append）或 ② 恰有一个未闭合 `<table` 标记且标记后无非表格正文（raw_single，且 det_N == 1）→ 触发并解码；③ tail-prose / text_only / multi-region raw / **未知形态** → **不触发、不解码、产物不变**（计 f6_skipped_shape）；部分缺表页维持 D-44 整页跳过。四类形态逐页回归（RBLK-2 解除条件） | 触发资格与冻结清单同源（发射形态分类规则一致）；excluded 页不触发不解码 → f6_triggered 语义归零；未知形态 fail-closed |
| D-54（v1.2 修订，re-review RBLK-3） | **持久化**（不变）：raw_single = 标记→文末整体替换；empty = 文末追加；原纯文本零删除。**采用门双公式（冻结，re-review RBLK-3 解除）**：规范化 = D-47 v1（剥标签→折叠空白→小写→字符 bigram）；① **cov_attempt = \|grams(attempt) ∩ grams(reread)\| / \|grams(attempt)\| ≥ 0.50**（重读必须恢复模型原读内容的大部分——attempt 是模型自己对该区域的读取，合法重读必然覆盖其大半）；② **cov_reread ≥ 0.30**（重读发明内容下限——新增结构标签/补全受控）；det_N == 1 保证 attempt 整段归属单区域（多区域页已排除，无切分歧义）。**标定协议**：T4 stage-A 先跑重读、归档 11 页实际分布 + 100% 人工复核（11 表全查对照页图），若冻结阈值拒好纳坏 → spike 失败，按 D-29 一轮校准调阈值并重跑 | 公式完整可执行（阈值/方向/规范化/切分全部冻结）；标定产物 = T4 stage-A 分布归档；人工复核 11 表全查（人群小到可全查） |
| D-55（v1.1 澄清，review 口径修正 2） | `reread_rules_generation` 字段沿用，**值由 1 升至 2**（F6 是新增触发输入 = 行为变更）；resume 回归：generation 2 的 F6 产物不被 generation 1 的旧运行复用，反之亦然 | v1.0 的"不变/＋1"矛盾消除 |
| D-56（v1.2 修订，re-review RBLK-2 尾部） | **多新表排序**：零块页的多检出区域先 **IoU ≥ 0.9 去重**（复用 M4 规则），再按 **D-44 双解释一致规则排序**（行/列双解释冲突 → 该区域集合标记歧义，**整页 F6 跳过**——保守）；排序后按序产出新表，保证与 GT 表序对齐。0→1/0→2/0→4 验收含乱序检测、重复区域、排序歧义三类 fixture | 零输出块消除了块身份错配，但多新表之间的**顺序歧义**仍在——沿用 D-44 的排序与歧义跳过机制（re-review 明确要求） |
| D-57 | 范围 = 表格；公式不纳入 F6（B0' 公式检测门 ~60% 未过，无合格区域信号；M5 维持关闭，重开条款不变） | 公式区域来源仍未解决；表格区域 53/53 覆盖 |
| D-58 | **raw 臂限 det_N == 1**（多区域 raw 页排除——共享整段原尝试文本的逐区域切分不安全，review RBLK-3 解除条件）；empty 臂独立有效性门（见 T4 判据②），**若评审否决无锚人工复核规则，empty 臂移出 v1**（杠杆降至 11 表 +0.47） | 按评审解除条件预置两条路径 |
