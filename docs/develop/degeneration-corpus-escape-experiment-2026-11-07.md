## 5. 裁决

1. **候选 D 达到 Q1.1 落地线（36.2% ≥ 30%）→ GO**：token 2048 档进 Q1.4 阶梯，排序按 Q2.1 类别感知（学术/试卷类提前，报纸靠后）。

3. **候选 C（切栏）**：Q2.1 显示 91% 报纸语料页含跨栏图片（切栏已知失效形态），主逃逸来源（行片段环）本身不需要切栏——切栏收益预期不足以覆盖其实现与回归成本，**本期不落地**，保留为阶梯预留位（表格数据见 §Q2.1 报告）。
4. **Q1.2（采样逃逸）继续按计划走 scratch 分支**：候选 D 只关闭 36.2%，剩余 136 页（尤其报纸 69 页行片段环）需要 repeat-penalty 采样档；Q2.1 判定报纸环为行片段 → 可用中高惩罚档，表格类环（4 页）低惩罚档。
5. **Q1.5 触发**：Q5.1 判定 24/28 纯截断页为环漏检形态 → 条件立项成立（决策 D-14）：`truncated` 页进入阶梯末档采样重试，改重试触发条件、`--resume` disposition 与场景 C 测试，随 Q1.2/Q1.4 落地一并实现。
