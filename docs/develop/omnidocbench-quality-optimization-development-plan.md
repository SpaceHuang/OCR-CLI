### 1.2 退化页的三个已证事实（决定方案主线）

1. **量化无关**：四档退化页数 203–218/档，F16 同样退化；balanced (Q5) Overall 反超 F16 2.1 分。任何量化侧工作都不是杠杆。
2. **版式强相关**：报纸 151 页中 92–94 页退化（61%），其次学术文献（~20%）、试卷（~16%）。触发条件为多栏密排 + 阅读顺序复杂。
3. **现有恢复手段已证明无效**：checkpoint 显示提交为退化的页面 `attempts=3`（`src/ocrx-output/src/lib.rs:728-731`，退化且未到 3 次必继续重试）——即原始渲染 + 0.94×/1.06× 两档扰动**三连全退化**。`--resume` 对退化页虽会 Reprocess（`lib.rs:2018-2021`），但重放的是同一组确定性尝试，结果必然复现。复读环是强吸引子，±6% 渲染缩放不构成逃逸；**修复退化页需要新的逃逸手段**。

## 2. 目标、非目标与行为基线

### 2.1 目标

1. **主目标**：balanced-all Overall 77.99 → **≥ 85** 为 v2 重构 GO 门槛（官方口径下等价于 Q1 退化语料缺口关闭 ≥53%，即"退化修复过半"原意的数值修正，BLK-1）；**≥ 88**（θ ≈ 76%）为进取检查点；满收参考 **91.1**（213 页退化语料全修复投影，`scripts/omnidocbench-projection.py` 口径）。四档复评全部走既有 runbook 与冻结 manifest，评分器与真值集不做任何修改。一切语料级实验结果必须换算为官方同粒度指标并给出预计全集增量，不得以按页均值直接外推。
2. 退化逃逸机制落地：对语料集（Q1.0 构建，213 页）的逃逸率有实测数据支撑；正常页面除 §2.3 声明的 Q3（think 清理）与 Q4（链接降级）两处显式产物修正外，**在同一解码代次内逐字节不变**（跨解码代次的正常页输出漂移按 §2.3 的 D-15 解码代次契约处置，为声明的预期变更）；逃逸路径（确定性链 `repeat_penalty → greedy`）同输入重跑逐字节可复现。
3. 产品缺陷清零：`<think>` 泄漏在适配器产物层剥离（导出脚本计数归零）、非法 bbox 链接降级为链接级处置（整页 `recognition_failed` 归零）。
4. 次级缺口全部有特征化结论：截断页、近纯图 PPT 空输出、en 公式/表格落差各自形成"可修/接受残余"的裁决记录。
5. 选档结论落档：balanced（Q5_K_M）作为质量/速度推荐档写入文档与技能说明。

### 2.2 非目标

- 不重训/不换模型、不改 GGUF 资产与 revision（`8a22290a`）、不改评分器与真值集。
- 不重开已裁决关闭的吞吐与引擎议题（BS/P1/P2/P3、CUDA/vLLM 均维持原裁决）；本方案全部杠杆以质量为判据，不引入吞吐回归门禁以外的性能目标。
- 不改 OCR prompt `ocr-markdown-v1`（字节冻结，v2 计划 §2.3）；退化重试的"提示词变体"路径不在本期范围（见决策 D-8）。
- 不把 en/zh 结构性落差（~15 分）的整体追平设为本期目标——先特征化，修不修由数据裁决。
- 不修改输出预算契约（16384 上限与上下文 20480 维持 D5 冻结值）。
- 不要求全量四档复评作为每个实验的验收——全量复评只用于里程碑门槛（决策 D-3）。

### 2.3 行为基线（继承并收窄）

- 正常页不变承诺（v1.2 按 BLK-3 收窄；**v1.5.1 按 D-15 加代次限定**）：**除 Q3（think 清理，波及 311 个含泄漏正常页）与 Q4（坏链接降级）两处显式定义的产物修正外**，正常页的模型原始输出与全部产物**在同一解码代次内**逐字节不变；扰动与采样手段只允许出现在退化重试路径（attempts ≥ 2）上，正常路径仍是纯贪心 argmax。Q3/Q4 各自携带"预期差异"回归用例（diff 恰为对应修正）；金集 30 页（无 think、无坏链接）零差异门禁为**代次内门禁**——它证明的是"无泄漏子集在其自身代次内"不变，不能外推到全部正常页，也不能跨代次使用（跨代次按下一条 D-15 条款处置）。
- **解码代次契约（v1.5 新增，D-15，响应 BLK-2）**：0.1.161 采用后，"正常页逐字节不变"承诺**仅对同一解码代次成立**。跨代次（0.1.152 → 0.1.161）的正常页输出差异（金集实测 38/91 文件漂移）是**声明的预期行为变更**，以三项门禁替代零差异承诺：① 代次键 `;decode=<gen>` 进 checkpoint 兼容参数，新旧代次页面不得混扫复用（含回归测试）；② 代次内确定性（同输入重跑逐字节一致）；③ 跨代次质量下限门禁——全量 balanced 各分量不得低于 0.1.152 基线（实测 84.92 vs 77.99，各分量全部为正，已满足）。0.1.152 代次的既有金集零差异门禁对其自身代次继续有效。
- 确定性可复现契约：采样逃逸的规格为**有序链 `repeat_penalty → greedy`**（penalty 先修改 logits，greedy 收尾选 token；顺序写入单测，不得实现为"greedy + repeat_penalty"的字面执行顺序）。该链自身确定性（无随机源），同输入重跑逐字节可复现；固定种子仅在扫参含随机采样变体（temperature/top-k）时需要。
- checkpoint v5 兼容：`attempts` 语义由 1..=3 扩为 1..=N（N ≤ 5，见 §4.4），数值字段旧文件可读；退化页在 `--resume` 下维持 Reprocess 语义不变。
- 退出码表、result schema 3、`scan-summary.json`、`document.md` 标记格式全部不变。

## 3. 执行拓扑：与 v2 重构的时序关系

基线是 v2 重构的**重构前**外部质量基线，本方案与 v2 计划的接缝必须显式管理：

```text
阶段 0（main，分析+数据，~0.5 天）
  Q1.0 实验语料构建 ──► Q2.1 报纸退化形态分类学 ──┐
  Q5.1/Q5.2/Q6.1 特征化（并行）                    │ 逃逸策略排序输入
  Q0.1 选档记录落档                                ▼
阶段 1（main 分支，无 pins 变更，~1–2 天）
  Q1.1 逃逸实验：扩档扰动（可选：批深 1 对照，实验分支常量改动）
        + 结构化重试（Q1.1c，无模型投影切栏，仅退化重试启用）
阶段 2（scratch 分支，~1–2 天）
  Q1.2 wrapper 0.1.161 升级 + repeat-penalty 扫参 → 语料逃逸率 + 子集评分
  ── 裁决点 ── GO：Q1.3 落地 + 修订 v2 计划 §2.2；NO-GO：数据归档关闭
阶段 3（main，~1 天，与阶段 2 可并行启动）
  Q3 think 剥离、Q4 bbox 链接降级（独立小改，先行合入）
  Q1.4 attempts 策略阶梯扩展（依赖阶段 1/2 裁决出的阶梯构成）
阶段 4（里程碑）
  全量 balanced 复评（90 min）→ 对照 §2.1 门槛（GO ≥ 85 / 进取 ≥ 88 / 满收参考 91.1）
  v2 重构完成后：四档全量终评 → 门槛判定，报告落 docs/test/reports/
```

- **Q1.2 的 pins 约束**：v2 计划 §2.2 冻结 `llama-cpp-2 = 0.1.152` / `llama-cpp-sys-2 = 0.1.153`。三期裁决已预留接口——"0.1.161 升级提案无性能论据，仅存绑定能力论据"；本方案补充的是**质量论据**（逐序列采样器 → 退化重试 repeat-penalty），按三期先例走 scratch 分支实验（S0 spike 同款模式，候选唯一性已由 `phase3-s0-wrapper-audit-2026-11-05.md` 认定：0.1.161，API 覆盖面完整，调用面静态比对兼容）。
- **Q3/Q4 先行合入的理由**：两处均为适配器/输出层小改，不触碰 v2 冻结面；先合入使 v2 重构迁移的是已修复代码，且 v2 验收复评时这两项缺陷已归零。
- **落地时序约束**：Q1.3（若 GO）必须在 v2 runtime 迁移**之前**定案——v2 以"已具备合批能力的 ocrx-runtime 为迁移输入，不回退"，采样逃逸若成立应属于被迁移的 runtime 形态，避免重构后再返工。

## 4. 优化杠杆与任务分解

### 4.0 Q0 —— 选档结论落档（纯文档）

基线结论一：量化不是瓶颈，四档极差 2.4 分，选档纯按速度/显存取舍，推荐 balanced。

| 任务 | 内容 | 验收 |
|---|---|---|
| Q0.1 | 将"推荐 balanced（Q5_K_M）"写入模型推荐文档与 `ocrx-skill` SKILL 说明（auto 推荐逻辑本身按内存选择的现状**不改代码**，仅补选档指南）；核对 `ocrx-models` 现行 auto 推荐与该结论无冲突 | 文评 + 既有测试全绿 |

### 4.1 Q1 —— 退化逃逸（主杠杆，Overall 77.99 → 88+ 的全部来源）

#### Q1.0 实验语料构建（一切实验的前置）

以 balanced 档 checkpoint 标记 `degenerated=true` 的 **213 页**（含 5 个退化∩截断交集页——有退化标记即进入重试路径，归属退化集）建立固定语料；**28 个纯截断页不计入语料与 Q1 收益账**（无重试入口，BLK-2），单列归 Q5.1；1 个缺失页归 Q4（其根因 bbox 链接整页失败被 Q4 直接修复）。同时把投影复算脚本入库：`scripts/omnidocbench-projection.py`（官方口径 + mapping 连接，v1.2 修订的唯一数字来源；重审已实际运行核实 77.9909 / 84.5674 / 91.1439，决策 D-11）：

- 产物：`assets/regression/omnidocbench-degeneration-v0.1/`——页清单（页码、来源类别、档位标记、attempts、warnings）、对应图片/PDF 子集映射（复用 `pdfs/mapping.json`）、**子集评分包**（从 `dataset/OmniDocBench.json` 过滤出语料页的真值子集 + 子集预测导出，供官方 `pdf_validation.py` 直接评分）。
- 快速评估环：语料 213 页按全集速率折算约 11.6 min/轮（全集 90 min），实验迭代成本降低 ~7×。
- 附带数据联查（一次性分析，写进语料报告）：语料页 × render-audit（172 页超 2880² 预算被 PDFium 等比缩）的交集——量化"渲染降采样是否为退化共因"，结论进 Q2.1 分类学。

验收：语料清单与子集评分包可一键复现；用基线二进制对语料重扫一轮，退化页集合与基线一致（确定性复现检查）；投影脚本输出与 §1.1 表一致（或在最终连接修订后重出权威表并同步 §1.1/§2.1 门槛绝对值）。

#### Q1.1 逃逸阶梯扩展实验（main 分支，无 pins 变更：扰动 + 结构化重试）

现状阶梯（原始 → 0.94× → 1.06×）已被全集数据证明不足。实验扩展候选阶梯（只作用于 attempts ≥ 2 的退化重试）：

- 候选 A：更宽缩放 0.85× / 1.15×（`render_perturbed` 分子分母换值，`src/ocrx-output/src/lib.rs:703`）；
- 候选 B：DPI 扰动（±10%，改变渲染像素栅格而非等比缩放）；
- 候选 C（Q1.1c，结构化重试）：无模型投影切栏重扫——对退化页用经典 whitespace 谷检测（Leptonica/Tesseract 版面分析同款思路，纯图像处理，零新权重、零 prompt 改动）切分栏块，逐栏以同一冻结 prompt 扫描，按栏序拼接。仅退化重试启用；bbox 坐标相对栏块失真可接受（退化页救文本优先，页面级 bbox 图片本已报废）。适用性由 Q2.1 分类学先行判定（跨栏图片/广告是已知失效形态）；
- 候选 D（Q1.1d，token 网格重试，E1/E2 实测证据）：`--max-image-tokens 2048` fresh 重扫——E1（`docs/develop/image-token-grid-2048-experiment-2026-11-07.md`，报纸 151 页）：1024 全阶梯失败的 92 页中 23 页（25%）被 2048 首试逃逸；E2（`docs/develop/formula-token-grid-2048-experiment-2026-11-07.md`，全部 313 含公式页）：**边际逃逸率 79%（27/34，全部 attempts=1）**，逃逸页样本 CDM 0.05 → 0.93（直达正常水平）；公式 CDM all 0.7925 → 0.9333（+14.1），**en 公式落差被分辨率消除（en 0.9365 反超 zh 0.9196）**。收益分解：坏页修复 +13.7 / 正常页仅 +0.4——**全局默认 1024 不变的铁据**（改默认 = 全量 2× 成本买 +0.4），2048 的全部价值在重试路径捕获。成本 ≈2× 编码（6.3 vs 3.27 s/页）。渲染 1:1 保真已由 E1 §1 核实（395/400 页精确复刻源像素），round-trip 失真假设关闭；报纸/学术以外类别（教科书/试卷等）的边际逃逸率待语料补测；
- 可选对照轴：批深 1 vs 8 重扫语料（常量改动在实验分支，验证"窗口共享上下文是否参与退化触发"；`WINDOW_DEPTH` 冻结值不动）。

验收（实验裁决线）：语料逃逸率（degenerated → 非退化提交且子集评分不低于原退化页基线）**≥ 30%**（分母 = 213 页退化语料，BLK-2 口径）才值得落地为阶梯变更；**实验报告必须同时给出官方同粒度子集指标与脚本外推的全集 Overall 增量**（θ 换算，§1.1），不得只报按页均值；数据（含逃逸页与未逃逸页清单）落 `docs/develop/`。无论 GO/NO-GO，正常页金集零差异门禁必须通过（正常页永不进入 attempts ≥ 2，理论零影响，仍以门禁证实）。

#### Q1.2 采样逃逸实验（scratch 分支，依赖 0.1.161）

按 S0 审计认定的唯一候选升级 wrapper/sys 至 0.1.161，在退化重试路径挂 repeat-penalty 采样器：

- 机制：0.1.161 `LlamaModel::new_context_with_samplers`（per-sequence sampler 配置，`llama.h` 推荐初始化路径）；退化页重试按批深 1 单独重扫（现状已是如此），对该 context 挂**有序采样链 `repeat_penalty → greedy`**（penalty 先改 logits、greedy 最后选 token；链顺序进单测——按"greedy + repeat_penalty"字面顺序实现将不产生惩罚效果）；首次尝试维持纯贪心不变。
- 出处注（v1.1）：该机制为行业标准实践——MinerU2.5 在生产中于识别阶段按版面类型动态调 frequency/presence penalty 抑制复读（文本段落高、表格低，避免惩罚表格/公式的合法重复结构）；本方案将该手段收窄到退化重试路径，正常页贪心不变。
- 扫参：repeat_penalty ∈ {1.1, 1.2, 1.3} × repeat 窗口 ∈ {64, 256}，固定种子（确定性契约，§2.3）；先在语料的报纸子集（92–94 页）上扫，选出最优组合后跑全语料。**扫参与评估按环内容类型分组**（Q2.1 分类学输出）：表格/公式类环使用低惩罚档，防止 `<td>` 等合法重复被误伤（MinerU 同款风险点）。
- 判据：语料逃逸率 + 子集 Overall 提升，对照 Q1.1 结果择优；**同时验证 escaped 页内容质量**（逃逸不等于修对——逃逸页必须过子集评分，防"逃出环但输出错"的假阳性）。
- 裁决：GO 条件 = 语料逃逸率 ≥ 50% 且子集评分改善可复现；GO 后执行 Q1.3 并修订 v2 计划 §2.2（pins 升级理由从"无性能论据"改为"退化质量论据 + 绑定能力论据"）。NO-GO 则数据归档，pins 维持冻结，主杠杆只剩 Q1.1 + Q1.4 的组合，预期收益相应下调并在本文修订记录中重算投影。
