# 决策点 X2 / B2 / D：spike 结论（2026-11-04，方案 §4 决策点）

**方案：** `docs/plan/scan-throughput-phase2-development-plan.md` §4 决策点 {X2, B2, D}
**性质：** 硬性 spike+决策门——决策文档通过前不进入实现。

## X2 跨文档混窗（spike）— **决策：不做（记录关闭）**

**假设**：小文档（<批深页数）窗口欠填充，混窗（一窗取多文档页）可回收吞吐。

**量化数据**（同机 Vulkan reference，编排器 + STEP_PROFILE 实测）：

| 场景 | 逐个调用 | 编排（文档级 FIFO 窗口） | 加速 |
|---|---:|---:|---:|
| md-small-20（20×2页，窗口 2/8 占位） | 154.3–155.8 s | 114.2 s | 1.35× |
| md-mixed（1/1/2/2/4/4/8/8 页） | 66.0 s | 50.9 s | 1.30× |

**欠填充的真实代价**（STEP_PROFILE 分解）：每 2 页文档窗口 ≈0.9–1.0 s（278 token，2/8 槽占位——批深 8 下 2 槽解码 ≈ 4 槽的 1.6 倍耗时而非 4 倍，GPU 图执行对槽数亚线性）；md-small-20 全部 20 窗的欠填充总代价 ≈ 10–15 s（解码段合计 ≈19 s vs 理想满窗 ≈6 s）。**但**每文档另有 ≈4 s 渲染+PNG 编码固有成本（与窗口无关），混窗回收上界 ≈10 s / 114 s ≈ **9%**。

**语义代价**（方案 §4 X2 行）：取消/批级错误回退（depth-1 整窗重扫）跨文档耦合——一个文档的退化重试会重扫他文档页，机制 A 的"同组合重放"契约被破坏，需要跨文档 checkpoint 组合键 + 恢复语义重设计（P4.2 同规格评审量级）。

**结论**：上界 ≈9% 墙钟 vs 语义复杂度重设计 + 评审成本——**不做**。若未来渲染/PNG 与解码重叠落地（单独提案），每文档固有成本下降后该比例会进一步缩小。

## B2 常驻进程（spike）— **决策：不做（与 X1 价值重叠核算后降级关闭）**

**假设**：load+init 每调用重复 ≈1.3–4 s，常驻进程可省。

**与 X1 的重叠核算**（方案要求的显式核算）：
- 多文档场景：X1 已把 verify+load 摊薄为每调用一次（实测 2.1 s/文档 × N → 一次），B2 残余价值 = 0。
- 单文档重复调用场景：B2 残余价值 = 每调用省 verify(1.4 s, reference) + load(≈0.7–1.1 s) ≈ 2 s/调用；但代价是进程生命周期管理（守护进程、模型失效重载、设备变化探测、健康检查），且与"scan 完整性契约"（每次全量校验，BLK-1）耦合——常驻进程若跳过逐调用校验即违反 BLK-1 裁决，若不跳过则只剩 load 摊薄 ≈0.7–1.1 s/调用。
- serve/watch 形态对比：watch 场景（目录监听）可由外部脚本串行调 scan 实现（每调用付 2 s 固定税），无守护进程状态风险。

**结论**：B2 残余价值 ≈0.7–2 s/调用且被 BLK-1 完整性契约约束——**不做**。未来若立项，须与"放宽完整性契约"（BLK-1 预留的独立提案）捆绑评审。

## D compact 推广决策 — **决策：不推广（数据记录在案）**

**质量门禁**（方案要求：金集相似度 ≥0.999 + 10 页人工抽检）：

- T0.4 实测（`phase2-t0-2026-11-03.md` §4）：compact vs reference 金集 `document.md` 可见文本 NED = 0.0058 → **相似度 0.9942 < 0.999**。相似度门禁未过，人工抽检免测。
- 速度侧数据（供未来重评）：24.4 s / 527 tok/s vs reference 同期 38.2 s / 447 tok/s = **1.57× 墙钟**，两遍偏差 0.38%。

**结论**：compact **保持 opt-in，不文档化为快速档**（质量红线优先）。数据归档于 `phase2-t0-2026-11-03-data/t04-*`；未来重新评估的触发条件：模型侧 compact 权重更新（revision 变化）后重跑同一门禁。

**四档 profile 推荐链**：不变（`recommend_profile` 仍按内存推荐，reference 仍为质量默认，compact 保持显式 opt-in）。
