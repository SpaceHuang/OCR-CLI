# Coverage

This draft contains 30 consecutive body-text pages from one source PDF. The
content target is intentionally narrow: reliable native text pages, not a
balanced OCR corpus of formulas, tables, charts, scans, and visual pages.

The draft should be accepted as the native qualified set only if all 30 pages
pass PDFium extraction, L2 validation, and human visual review. If any page
contains important visual content or fails validation, replace it with another
text-heavy page from the same source PDF rather than lowering the threshold.
